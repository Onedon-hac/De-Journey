The Host Discovery CLI Tool

I Built a Network Scanner in Pure Bash (Because Nmap Too Chilled Out)

Category: Tools & Terminal Chaos

Authour: Ishaque Osman (Don Richy) | SEC-LAB

Read Time: 2 mins

The Problem: Why reinvent the wheel?

Look, Nmap is great. We all love Nmap. But sometimes you just want to know "Who on earth is using up all the Wi-Fi right now?" without launching a tool that looks like it's trying to hack NASA

I wanted something fast, clean, zero-dependency, and pretty to look at. So instead of installing heavy frameworks, I did what any reasonable security student would do: I wrote a complete network host scanner in pure Bash.

What Makes This Tool Cool (And Why My Terminal Looks Like a Disco)

  • Zero Install Required: If your Linux box has "ping" and "bash", it runs. No "apt install", no dependencies, no excuses.
  • Regex Built-in: If you try entering "192.168.1.lol" as your IP prefix, the script will politely (and loudly in red text) tell you to try again.
  • Smart Noie Control: Nobody wants to read 250 lines of [ OFFLINE ]. By default, it hides the ghost IPs and only highlights active targets.
  • Graceful Rage-Quitting: Ever hit "Ctrl + C" on a script and your terminal screen turns bright green forever? Fixed tha. A custom signal trap catches "SIGNIT" and shuts down cleanly
  • Dynamic ANSI Light Blue Banner: Because standard text is boring and terminal tools deserve drip.
